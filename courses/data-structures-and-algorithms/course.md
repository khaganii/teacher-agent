## Təlim nəticələri (FTN / CLO)

1. Əsas verilənlər strukturlarını və alqoritm anlayışlarını izah edir.
2. Verilənlər strukturlarının iş prinsiplərini təhlil edir və fərqlərini şərh edir.
3. Konkret məsələlərin həlli üçün uyğun alqoritm və verilənlər strukturunu seçir və tətbiq edir.
4. Alqoritmlərin zaman və məkan mürəkkəbliyini qiymətləndirir və müqayisə edir.
5. Müxtəlif həll üsullarını qiymətləndirir və optimal alqoritmi əsaslandırır.
6. Alqoritmik həlli formal şəkildə təsvir edir və proqramlaşdırma mühitində reallaşdırır.
