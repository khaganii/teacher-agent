# Week 2 — Warm-up: dəyişənlər, operatorlar, şərt, dövr (20 sual)

Mühazirədə Java-nı dəyişənlərdən şərt/dövrə qədər (array-sız) keçdikdən sonra
sinifdə işləmək üçün. Array bura daxil deyil — hələ keçilməyib.

## Dəyişənlər və operatorlar

1. Ekrana adını çap et.
2. İki ədəd oxu, cəmini, fərqini, hasilini, bölməsini və qalığını (`%`) çap et.
3. Məbləğ və faiz dərəcəsi oxu, faizin məbləğini hesabla.
4. Selsi dərəcəsini oxu, Fahrenheitə çevir (`°F = °C*9/5+32`).

## if/else

5. Bir ədəd oxu, cüt ya tək olduğunu yaz.
6. Üç ədəd oxu, ən böyüyünü tap.
7. Bir ədəd oxu, mənfi, müsbət, yoxsa sıfır olduğunu yaz.
8. Yaş oxu: 0-12 "uşaq", 13-17 "yeniyetmə", 18+ "yetkin" yaz.

## switch

9. Bal (0-100) oxu, onluğa görə hərf ver (90+ → A, 80+ → B, … — əvvəlcə
   `bal/10` hesabla, sonra `switch`).
10. 1-7 arası ədəd oxu, həftənin gününü çap et.
11. Ay (1-12) oxu, mövsümü çap et (12,1,2 → qış və s.).
12. 1-4 arası ədəd oxu, sadə kalkulyator menyusu göstər: 1→toplama, 2→çıxma,
    3→vurma, 4→bölmə adını çap et.

## for

13. `n` oxu, 1-dən n-ə qədər ədədlərin cəmini tap.
14. `n` oxu, 1-dən n-ə qədər neçə cüt ədəd olduğunu say.
15. `n` oxu, n faktorialını hesabla.
16. Bir ədəd oxu, onun 1-dən 10-a qədər vurma cədvəlini çap et.

## while

17. `while` ilə istifadəçidən ədəd al, 0 yazana qədər davam et, neçə ədəd
    daxil etdiyini çap et.
18. Ədəd oxu, `while` ilə rəqəmlərinin sayını tap.
19. Ədəd oxu, `while` ilə tərsinə çevir (1234 → 4321).
20. Ədəd oxu, `while` ilə rəqəmlərinin cəmini tap (1234 → 10).
