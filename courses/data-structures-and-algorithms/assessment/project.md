# Layihə — 20%

Rəsmi qiymətləndirmə cədvəlində layihə 20% çəkiyə malikdir və 12-14-cü həftələrə
aiddir. Mən onu **tələbə təqdimatı** formatında keçirirəm və 10-14-cü həftələrə
yayıram — hamısını üç həftəyə yığmaq nə vaxt baxımından mümkündür, nə faydalı.

## Format

Hər tələbə **iki qohum pattern** alır və hansını nə vaxt seçmək lazım olduğunu
izah edir. İki ayrı mövzu deyil — bir **qərar**. Bu, FTN 3 və FTN 5-ə birbaşa
uyğundur ("uyğun alqoritmi seçir", "optimal alqoritmi əsaslandırır").

### Təqdimat (12-15 dəq)

1. 4-5 slayd — hər iki pattern nədir, nə vaxt tanınır, mürəkkəbliyi
2. **Canlı implementasiya** — birini ekranda sıfırdan yazır (5 dəq, hazır kod yapışdırmaq yoxdur)
3. Bir məsələni həll edib izah edir
4. Sinifdən 2 sual

### Ön yoxlama — məcburidir

Slaydlar və kod təqdimatdan **3 gün əvvəl** GitHub-a yüklənir. Müəllim baxıb
təsdiq edir. Bunsuz zəif tələbə sinfə səhv məlumat öyrədir və onu düzəltmək iki
qat vaxt aparır.

### Dinləyicilər

Hər təqdimatdan sonra həmin pattern-in bir məsələsi **bütün qrupa** ev tapşırığı
olur. Beləcə təqdimat "öz növbəni gözlə" yox, sinfin materialı olur.

## Mövzu cütləri

| # | Mövzu | Əsas sual |
|---|---|---|
| 1 | Two pointers ↔ Sliding window | İkisi də massiv gəzir — fərq nədir? |
| 2 | DFS ↔ BFS | Hansı halda hansı? Niyə BFS ən qısa yolu tapır? |
| 3 | Top-K: sortlama ↔ heap | n log n vs n log k — nə vaxt fərq edir? |
| 4 | Memoization ↔ Tabulation | Eyni nəticə, fərqli yol — üstünlüklər? |
| 5 | HashMap ↔ əvvəlcə sortlamaq | Təkrar tapmaq üçün hansı ucuzdur? |
| 6 | Linear search ↔ Binary search | Binary search nə vaxt işləmir? |
| 7 | Adi stack ↔ Monotonic stack | "Növbəti böyük element" niyə O(n)-ə düşür? |
| 8 | Rekursiya ↔ İterasiya | Stack overflow nədir, nə vaxt olur? |
| 9 | Massiv ↔ Əlaqəli siyahı | Hansı əməliyyatda hansı qazanır? |
| 10 | Greedy ↔ DP | Greedy hansı məsələdə sınır — əks-nümunə göstər |

10 mövzu = yarımqrupda 10 nəfər. İki yarımqrupda eyni siyahı təkrarlanır.

## Qrafik

Mövzular 9-cu həftədə paylanır. Təqdimatlar 10-14-cü həftələrdə, hər məşğələdə
2 nəfər: 5 məşğələ × 2 = 10 ✓
